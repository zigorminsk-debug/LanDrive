Сетевые диски — NetDriveMapper
================================

Сборка EXE (на Windows):
  дважды щёлкните build.bat
  появится файл NetDriveMapper.exe в этой папке.

Использование:
  1. Запустите NetDriveMapper.exe.
  2. Выберите количество дисков (0–10). Появятся поля для каждого.
     0 — стереть сохранённые данные, отключить диски, удалить ярлыки.
  3. Для каждого: UNC-путь (\\IP_или_имя\шара), буква, название ярлыка.
  4. Настройки сохраняются в %AppData%\NetDriveMapper\config.ini.

При каждом следующем запуске программа:
  — отключает ранее подключенные диски;
  — удаляет их ярлыки с рабочего стола;
  — подключает шары заново на те же буквы;
  — создаёт ярлыки на рабочем столе.

Изменить настройки (поля заполнены сохранёнными данными):
  запустить EXE, удерживая Shift,
  либо NetDriveMapper.exe /setup

Записать всё заново (пустая форма; старые диски снимутся только после «Сохранить»):
  запустить EXE, удерживая Ctrl,
  либо NetDriveMapper.exe /reset

Отмена в диалоге не трогает уже сохранённый config.ini.

Учётные данные Windows для шары используются текущие (уже вошедший пользователь).
